01

Project Context & Objective

ContextOS is engineered as an sovereign, local-first personal knowledge substrate. Its purpose is to bridge the continuous amnesia between disparate foundation model sessions by transforming raw, multi-year AI conversation transcripts into structured, queryable semantic memory without routing private thought records through third-party aggregators.

Rather than functioning as a transient chat client or generic prompt organizer, ContextOS acts as an operating system kernel for human thought assembly—producing compact, highly grounded context packages that prime newly initiated model environments with instant domain fluency.

02

Architecture

ContextOS implements a strictly client-orchestrated execution topology. The browser sandboxes both relational indexation and vector retrieval routines directly on the user's silicon:

database
SQLite-WASM with Origin Private File System (OPFS) Guarantees transactional integrity and sub-millisecond retrieval across multi-gigabyte document tables directly within persistent virtual sandboxes.
memory
In-Process Embedding & Vector Cache Runs quantized 384-dimensional mini-embeddings over WebGPU/WASM threads, executing dot-product similarity searches with zero cloud inference roundtrips.
lock
Zero-Telemetry Vault Boundary Plaintext queries, project graphs, and transcribed transcripts never leave the active browser origin unless deliberately exported via cryptographic export manifests.
03

Important Decisions

1. Local SQLite via WebAssembly instead of IndexedDB Ratified

IndexedDB suffers from severe query planning limitations, volatile cursor serialization overhead, and unreliable quota evictions across Safari and Chromium. SQLite-WASM over OPFS provides true ACID guarantees, complex nested SQL CTEs, and identical query mechanics to native enterprise storage.

2. Clean Editorial Prose over Rigid XML/JSON Schemas Ratified

Empirical evaluation across Claude 3.5 Sonnet, GPT-4o, and Gemini 1.5 Pro revealed that frontier models exhibit noticeably superior contextual synthesis, reasoning depth, and instruction adherence when consuming human-curated editorial prose rather than delimiter-heavy XML/JSON node trees. The handoff format is intentionally styled as an authoritative executive brief.

3. Self-Contained In-Process Embeddings Ratified

External vector databases introduce API latency, credential leakage vectors, and persistent subscription overhead. Housing our embedding pipeline inside Web Workers provides instantaneous zero-cost indexing during conversation imports.

04

Why Those Decisions Were Made

The driving thesis was absolute user autonomy. Historical testing demonstrated that when personal knowledge systems rely on proprietary server infrastructure, users instinctively censor their deepest exploratory prompts and vulnerability-laden drafts.

Furthermore, empirical latency benchmarks proved that local SQLite queries resolve in 2.3ms on average, compared to 180–420ms for edge-replicated cloud databases. The offline durability guarantees that ContextOS retains zero external operational dependencies.

What Has Already Been Tried & Failed Approaches

  • close
    Supabase Edge Gateway streaming proxy: Abandoned after testing. Imposed an unacceptable 420ms Time-To-First-Token (TTFT) penalty and required persistent user auth tokens, negating the offline-first privacy model.
  • close
    BroadcastChannel multi-tab sync: Prompted frequent race conditions and deadlocks during concurrent multi-tab write bursts. Fully deprecating in favor of navigator.locks (WebLocks API) combined with shared OPFS handles.
07

Known Constraints & Boundary Rules

• Browser Memory Heap Quotas: Total in-memory vector cache must not exceed 256MB on mobile WebKit runtimes; dynamic LRU eviction cleans cold embeddings.

• Client Chunking Caps: Markdown export payloads for context handoff must remain bounded below 4,000 tokens to preserve ample working reasoning space for 8k-output models.

• Zero External Network Calls: No analytics pixels, CDN script tags, or remote web fonts may be loaded dynamically outside the self-contained package envelope.
